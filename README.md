## MeuAppFlask

Aplicativo Flask que inicia um servidor local e abre automaticamente a página no navegador.

---

## Estrutura do Projeto

novo tudo certo/
│
├─ app/ # Código principal do Flask
├─ services/ # Serviços auxiliares
├─ src/ # Scripts adicionais
├─ templates/ # HTML do Flask
├─ uploads/ # Arquivos enviados
├─ main.py # Script principal
├─ requirements # Dependências do Python
└─ README.md # Este arquivo
